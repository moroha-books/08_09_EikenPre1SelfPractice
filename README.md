# 英検準1級 通勤リスニング

前回の成績分析にもとづいて作った、車で聞くためのオリジナル音声教材です。

| 弱点（前回の結果） | 対応するカテゴリ | 内容 |
|---|---|---|
| リスニング Part 2：3/12 | **説明文（Part 2形式）** 6本 | 本番形式の説明文 → 質問2問 → 正解と言い換えの解説 → 重要語 → ゆっくり版 |
| 語彙 大問1：10/18、句動詞の誤解 | **句動詞・勘違い注意** 48語 | 例文 → 考える間 → 訳 → 「直訳するとこう誤解しやすい」→ 言い換え |
| Part 1：6/12、「わかったつもり」 | **会話の本音（Part 1形式）** 10問 | 皮肉・遠回しな断りなど、言葉の裏の意図を読み取る |
| 内容一致 3/7、要約 8/16 | **言い換え・誤読トラップ** 24文 | 本文→選択肢の言い換えパターン。`has yet to` `anything but` など意味を逆に取りやすい表現も |

すべてオリジナルの文章なので、GitHubで公開しても問題ありません。

---

## 1. 音声を作る（VS Code）

1. このフォルダを VS Code で開きます（ファイル → フォルダーを開く）。
2. ターミナルを開いて（Ctrl + @）、次を実行します。

```bash
pip install -r requirements.txt
python generate.py
```

- `audio/` フォルダに mp3 が、ルートに `tracks.js`（プレイリスト）ができます。
- インターネット接続が必要です（Microsoft Edge の音声合成を使うため）。数分かかります。
- ffmpeg などの追加ソフトは不要です。

### 便利なオプション

```bash
python generate.py --only lecture   # 説明文だけ作る（phrasal / dialogue / lecture / paraphrase）
python generate.py --force          # 作成済みのmp3も作り直す
```

一度作った音声のパーツは `.cache/` に保存されるので、作り直しは速く終わります。

### 声・速さ・間を変えたいとき

`generate.py` の先頭にある設定を変更します。

```python
EN_RATE = "+0%"        # 英語の速さ。慣れてきたら "+10%" で本番より速く
EN_SLOW_RATE = "-15%"  # ゆっくり版
THINK_SEC = 4          # 考える時間（秒）
ANSWER_SEC = 7         # 問題を解く時間（秒）
```

使える声の一覧は `edge-tts --list-voices` で確認できます。イギリス英語にしたいときは `en-GB-RyanNeural` などに変更します。

### 教材を追加するとき

`content/` の JSON ファイルに項目を追加して、もう一度 `python generate.py` を実行します。
新しいトラックは `"tracks": [...]` に1ブロック追加するだけです（既存の形式をコピーしてください）。

## 2. パソコンで確認する

`index.html` をダブルクリックして開けば、ブラウザで再生できます。

## 3. GitHub Pages で公開する

1. GitHub で新しいリポジトリを作ります（無料プランで Pages を使うには **Public** にします）。
2. このフォルダをそのまま push します（`.cache/` は `.gitignore` で除外済みです）。

```bash
git init
git add .
git commit -m "英検準1級 通勤リスニング"
git branch -M main
git remote add origin https://github.com/<ユーザー名>/<リポジトリ名>.git
git push -u origin main
```

3. リポジトリの **Settings → Pages → Branch** で `main` と `/ (root)` を選んで **Save** を押します。
4. 1〜2分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で開けるようになります。

`audio/` と `tracks.js` も必ず push してください（ページはこの2つを読み込みます）。

## 4. 車での使い方

- スマホでページを開き、**ホーム画面に追加**しておくとアプリのように起動できます。
- **出発前に**カテゴリとトラックを選んで再生してください。走行中は画面を操作しないでください。
- Bluetooth や CarPlay / Android Auto で接続していれば、**ハンドルのボタンで再生・一時停止・曲送り**ができます（車種により異なります）。
- 「連続再生」で次のトラックへ自動で進みます。ボタンを押すと「1曲リピート」「1曲で停止」に切り替わります。
- 聞いた位置は自動で保存され、次に開いたときは続きから再生します。聞き終えたトラックには ✓ が付きます。
- 速度ボタンで 0.8x 〜 1.25x に切り替えられます。

## 1週目の予定（追加分 約2時間45分）

その日の新しいトラックを**行き**に聞き、**帰り**に同じトラックをもう一度聞きます。2回目は、問題の間で答えを声に出しましょう。

| 曜日 | 新しく聞くトラック | 時間 |
|---|---|---|
| 月 | 説明文 W1-1〜5 ／ 会話の本音 11〜15 ／ 句動詞 セット5 | 約39分 |
| 火 | 説明文 W1-6〜10 ／ Real-Life 1〜6 ／ 言い換え 25〜36 | 約39分 |
| 水 | 説明文 W1-11〜15 ／ 会話の本音 16〜20 ／ 句動詞 セット6 | 約38分 |
| 木 | 会話表現 セット7 ／ 言い換え 37〜48 ／ 最初の説明文6本（Urban Heat Islands など） | 約41分 |
| 金 | 復習：W1 説明文15本 通し（通常速度 → ゆっくり版でシャドーイング） | 約33分 |

- 1週目に追加したカテゴリ
  - **Real-Life（Part 3形式）**：先に状況と質問を聞いてから本文を聞く、本番と同じ形式です。条件に合う情報だけを選ぶ練習をします。
  - **復習（本文だけ連続）**：その週の説明文の本文だけを続けて流します。週末や、解説を聞かずに英語だけに集中したい日に使います。
- タイトルが「W1」のトラックが1週目の追加分です。

### 1週目分を追加するとき

1. 新しい `generate.py` と、`content/` の `w1_` で始まるファイルを上書き・追加します（zipの中身でフォルダごと上書きしてかまいません）。
2. `python generate.py` を実行します。作成済みの音声はそのまま使われ、新しいトラックだけが作られます。
3. `audio/` と `tracks.js` を含めて GitHub に push します。

```bash
git add .
git commit -m "1週目の教材を追加"
git push
```

## おすすめの聞き方

- **行き（頭がすっきりしている時間）**：説明文（Part 2形式）を1〜2本と、会話の本音を1本。問題の間に、声に出して答えを言いましょう。
- **帰り**：句動詞または言い換えを1本。例文の後の間で、声に出して日本語の意味を言いましょう。
- 同じトラックを**3日続けて**聞いてから次に進むと、定着しやすくなります。
- 運転していない時間に、正解できなかった問題の英文を `content/` の JSON で確認しましょう。
